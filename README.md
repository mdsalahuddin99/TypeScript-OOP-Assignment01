## 💻 Coding Problems Solved
In `solutions.ts`, you will find solutions for:
1. **filterEvenNumbers:** Filters even numbers from an array.
2. **reverseString:** Reverses a given string.
3. **checkType:** Uses Type Guards to distinguish between strings and numbers.
4. **getProperty:** A generic function to access object properties safely using constraints.
5. **toggleReadStatus:** An interface-based function to modify object properties.
6. **Student Class:** Demonstrates OOP Inheritance and strict string formatting.
7. **getIntersection:** Finds common elements between two numeric arrays.
